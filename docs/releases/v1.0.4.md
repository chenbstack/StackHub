## 更新内容

- 接入 Sparkle 自动更新：启动时及每小时检查一次 GitHub Release，发现新版仅在面板右上角显示小蓝色下载按钮，点击后下载、校验、安装并重启。
- 删除右上角“健康”标记；语言切换和下载按钮默认透明，鼠标悬停时显示底色。
- 项目、CI、日志和编辑页面改用悬浮滚动条，不再为滚动轨道预留内容宽度。
- 改进面板定位与高度调整，优化项目和流水线卡片布局。
- 优化 GitLab 流水线增量刷新、阶段分组和耗时显示，并增加菜单栏运行中／未读失败数量。
- 更新包和 appcast 索引使用 Ed25519 签名验证。
- 修复原生 SwiftPM 构建下简体中文资源查找的兼容问题。

## 安装与更新

- 适用于 Apple Silicon Mac，要求 macOS 14 或更高版本。
- 下载 `StackHub-1.0.4-macos-arm64.zip`，解压后将 `StackHub.app` 放入“应用程序”。
- 尚未内置 Sparkle 的旧版需要手动安装一次；此后可使用右上角下载按钮更新。
- 更新重启会正常停止 StackHub 管理的本地服务，重新打开后需按需启动服务。
