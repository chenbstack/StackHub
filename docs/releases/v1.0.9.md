## 修复

- GitHub Actions 自动刷新时会补拉最新流水线缺失的步骤详情，无需点击“查看”。
- GitHub 和 GitLab 会在后续刷新中重试缺失的步骤详情，即使流水线已不在本次增量结果中。
- 流水线从运行中变为完成时会再次同步步骤状态，避免沿用运行时的旧详情。
- 流水线结果和每次成功获取的步骤详情立即显示；保留已有缓存和日志，各实例继续独立刷新。

## Fixes

- Automatically fetch missing job details for the latest GitHub Actions runs without opening the detail view.
- Retry missing GitHub and GitLab job details on later refreshes, including completed runs absent from incremental responses.
- Refresh job details once a running pipeline completes, then reuse the completed cache.
- Display summaries and successful detail responses immediately while preserving cached data, logs, and independent instance refreshes.
