## 更新内容

- GitHub 与各 GitLab 实例独立刷新，结果完成即显示；一个公司内网实例离线时，不再阻塞其他实例或它们的下一轮刷新。
- 保留离线实例的项目及流水线缓存，按实例合并结果，避免较慢的请求覆盖其他实例的新数据。
- GitHub／GitLab 请求超时统一为 3 秒。首次连接超时、DNS 失败或网络不可达后，停止该实例本轮后续请求，不再逐个项目等待超时。
- 离线实例的自动重试从 1 分钟逐步延长至最多 5 分钟；手动刷新可立即重试，恢复连接后回到正常刷新间隔。
- 刷新按钮在部分实例仍加载时可继续使用；请求去重，并通过按钮状态和悬停说明显示部分连接失败。
- 补齐 macOS 应用图标及打包配置，Finder／启动台显示 StackHub 图标。
- 菜单栏仅显示 RUN 或仅显示 FAIL 时垂直居中；两种计数都有时保持上下两行。

## 验证

- 53 项测试通过，包括多实例独立刷新、离线缓存保留、失败后停止后续请求、手动恢复和旧请求隔离。
- 使用本地无响应 HTTP 服务验证，请求约 3 秒后超时。
- 公司内网和真实 VPN 切换尚未现场验证。

## 安装与更新

- 适用于 Apple Silicon Mac，要求 macOS 14 或更高版本。
- 已安装支持 Sparkle 的版本，可点击右上角蓝色下载按钮更新并重启。
- 手动安装：下载 `StackHub-1.0.5-macos-arm64.zip`，解压后将 `StackHub.app` 放入“应用程序”。
- 更新重启会停止 StackHub 管理的本地服务，重新打开后需按需启动服务。
