## 改进

- 最近流水线按更新时间合并展示所有实例的活动，最多显示 20 个项目，每个项目显示最新一条流水线。
- 关注项目上限为 5 个，新增数量提示和取消关注菜单；已有超过上限的关注记录会保留。
- GitLab 项目级同步每个实例每轮最多刷新 10 个仓库，优先处理关注、运行中和新活动项目，并轮询其余项目；项目活动索引每轮只获取最近 30 个项目。
- GitHub 每轮最多获取和刷新 5 个仓库，同时限制流水线详情预加载数量，减少后台请求。
- 同一实例上一轮尚未完成时，跳过重复的自动或手动刷新；不同实例继续独立刷新，保留离线缓存和 3 秒网络超时。

## Improvements

- Show the latest pipeline from up to 20 projects across all connected instances, ordered by pipeline update time.
- Limit followed projects to five and add a count and unfollow menu. Existing follow lists above the limit are preserved.
- Poll up to 10 repositories per GitLab instance on each project-level sync. Prioritize followed projects, running pipelines, and new activity while rotating through other projects. Fetch only the 30 most recently active projects for the activity index.
- Fetch and refresh at most five GitHub repositories per cycle and bound pipeline detail prefetching to reduce background requests.
- Skip duplicate automatic or manual refreshes while the same instance is still busy. Keep independent instance refreshes, offline caches, and the 3-second network timeout.
