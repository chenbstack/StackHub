## 更新

- 支持 Sparkle 的已安装版本可使用面板右上角的蓝色下载按钮更新并重启。
- 手动安装：下载 `StackHub-1.0.7-macos-arm64.zip`，解压后将 `StackHub.app` 放入“应用程序”。适用于 Apple Silicon 和 macOS 14 及以上。
- 更新重启会停止 StackHub 管理的本地服务，重新打开后需按需启动服务。
