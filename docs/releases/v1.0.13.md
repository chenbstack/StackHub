## 更新内容

- 每个本地服务可独立选择 JDK 和 Node.js：自动识别、已安装版本或自定义路径，无需安装 jenv/nvm。
- 自动模式优先读取 `.java-version`、`.nvmrc` 和 `.node-version`，没有项目配置时沿用 `.zshrc`；手动选择优先级最高，并显示实际版本、路径和来源。
- 启动前检查指定运行时，版本缺失时明确报错，不自动下载或静默切换；环境仅作用于当前服务，重启后应用更改。
- 修复日志无法使用快捷键复制、输入框无法粘贴的问题，补齐原生编辑菜单和常用快捷键。

## What's new

- Choose a JDK and Node.js runtime independently for each local service: automatic detection, an installed version, or a custom path. jenv/nvm are optional.
- Automatic mode reads `.java-version`, `.nvmrc`, and `.node-version`, falling back to your `.zshrc` environment when no project version file exists. Manual selections take priority; resolved versions, paths, and sources are shown in settings.
- Validate requested runtimes before startup. Missing versions report a clear error without downloading or silently selecting another version. Runtime changes are isolated per service and apply after restart.
- Restore keyboard copy in logs and paste in text fields with a native Edit menu and standard editing shortcuts.
