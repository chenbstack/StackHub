## 改进与修复

- 实例管理现在显示真实的 API 连通性，区分未检测、检测中、连接正常、凭据或权限问题及网络不可达。支持单独重试、检测全部，并在页面打开时定时检测；各实例独立完成，超时仍为 3 秒。
- 修复菜单栏显示历史失败数量的问题：仅统计面板对应的最新流水线，在打开 CI 页面后及时清除已查看的失败提醒。
- 自动识别并跳过已关闭 CI/CD 的 GitLab 项目，避免将其误报为同步失败；保留缓存，后续刷新会重新检查是否启用。
- 将流水线的“部分连接失败”改为“部分同步失败”，与实例连通性状态区分。

## Improvements and fixes

- Instance management now checks real API connectivity and distinguishes unchecked, checking, connected, credential or permission errors, and unreachable instances. Retry one instance or check all, with periodic checks while the page is open. Checks complete independently and retain the 3-second timeout.
- Fix historical failures appearing in the menu bar: counts now follow the latest pipelines shown in the panel, and opening the CI page promptly acknowledges viewed failures.
- Detect and skip GitLab projects with CI/CD disabled instead of reporting a sync failure. Preserve cached data and check again for CI/CD being re-enabled.
- Rename the pipeline refresh warning to “Some syncs failed” to distinguish sync errors from instance connectivity.
