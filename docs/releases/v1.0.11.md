## 修复

- 修复 GitLab 项目级同步固定刷新旧列表前 8 个项目，导致 CE、EE 同时推送却只显示一个仓库流水线的问题。
- 每次同步获取最新项目活动顺序，优先刷新新活动、运行中和已关注的项目，并轮询其余项目，避免长期遗漏。
- 每个项目的流水线请求完成后立即显示结果；后续请求超时也会保留已获取的数据、缓存和成功同步进度。
- 各实例继续独立刷新，网络超时保持 3 秒。

## Fixes

- Fix GitLab project-level sync repeatedly checking only the first eight projects in an outdated index, which could hide one repository's pipeline when CE and EE were pushed together.
- Refresh project activity ordering on each sync, prioritize new activity, running pipelines, and followed projects, and rotate through the remaining projects.
- Display each project's pipeline results immediately and preserve successful results, cached data, and sync progress if a later request times out.
- Keep independent instance refreshes and the 3-second network timeout.
